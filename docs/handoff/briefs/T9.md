## Scope

1. **Follow a page or an agent**: `follows(target_kind, target_id, owner_uid)` in the follower's `UserDirectory`, and a
   follower list kept with the target's owner. New chats on that page, that agent's posts, and new page versions appear
   in the follower's feed without anyone adding them. Following needs the right to open the target (the same checks as
   opening the artifact; an agent can be followed by people in a chat where it is shared).
2. **One feed**: `feed(id, kind, ref, at, read)` in `UserDirectory`; kinds: tag, agent post, approval waiting (T6),
   assumption to confirm, question an agent asked, new page version, new chat on a followed page. `addFeed()` is called
   by the chat and artifact code on those events for each follower / person concerned; the sidebar socket pushes it; Web
   Push via T3. Off-the-record chats never reach the feed (T5's rule). A feed view (sidebar entry with a count) with an
   **Unread** switch, mark read, open the item; "Needs you" is the filter of items that need an answer.
3. Feed items for the user's own agents' runs (sent, not today, failed, needs sign-in).

4. **What is there now** (merged into feat/agents at cd654c9): Web Push is `UserDirectory.push(message)` (T3); tags
   reach a person as a `Tag` on `UserDirectory.touchChat` / `touchSharedChat` over the sidebar socket (shared chats);
   chat kinds and the off-the-record rule are in `shared/chat-kinds.ts` (`mayLeave(leaving, ...kinds)`, also used by T7's
   memory notes); run statuses are `RunStatus` in `shared/runs.ts` (running, sent, not_today, failed, needs_sign_in),
   each agent has a home conversation (chats rows with `agent_id`, `ChatRows.list`), and T4's UI PR (coming) adds run
   notices over the sidebar socket: feed items for runs should reuse those, not add a second path. Page versions are
   published through `publishVersion` (`worker/storage/`) and a page's Discuss chat hears of them via `#tellPageChat`
   in `worker/chat-agent.ts`. T7 (#111, memory notes) adds unconfirmed facts: "assumption to confirm" items come from
   those once it is merged.
